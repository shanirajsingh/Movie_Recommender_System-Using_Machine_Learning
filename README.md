# 🎬 Movie Recommender System

A Machine Learning based Movie Recommender System built using Python, Streamlit, and TMDB API.

The application recommends similar movies based on user selection and displays movie posters dynamically using TMDB API.

---

# 🚀 Live Demo

https://movierecommendersystem-9qfmvdr355husclow.streamlit.app/

---

# 📌 Features

- Movie recommendation system using cosine similarity
- Interactive Streamlit UI
- TMDB API integration for posters
- Fast recommendation engine
- Optimized compressed similarity matrix
- GitHub & Streamlit Cloud deployment ready

---

# 🛠 Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- TMDB API
